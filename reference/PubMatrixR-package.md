# PubMatrixR: Pairwise Literature Co-occurrence Matrices from 'NCBI' Entrez

\`PubMatrixR\` provides functions to query 'NCBI' Entrez 'E-utilities'
for pairwise co-occurrence counts across two term sets and to visualize
the resulting matrix-like data frame with heatmap helpers.

## Main functions

- \[[`PubMatrix`](https://toledoem.github.io/PubMatrixR-v2/reference/PubMatrix.md)\]
  Query 'NCBI' and build a pairwise count matrix.

- \[[`plot_pubmatrix_heatmap`](https://toledoem.github.io/PubMatrixR-v2/reference/plot_pubmatrix_heatmap.md)\]
  Plot overlap percentages with clustering.

- \[[`pubmatrix_heatmap`](https://toledoem.github.io/PubMatrixR-v2/reference/pubmatrix_heatmap.md)\]
  Convenience wrapper for heatmap plotting.
